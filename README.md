# STICKMAN CO-OP · ROGUELIKE

Браузерный 2D-рогалик на **1–8 игроков**. Платный сервер **не нужен**: соло и боты работают локально, а кооп — напрямую **P2P** (хост в браузере + бесплатный PeerJS для сигналинга).

**Постоянная ссылка:** https://formahedon51.github.io/stickman-roguelike/

**Репозиторий:** https://github.com/formahedon51/stickman-roguelike

## Режимы

- **▶ Одиночная игра** — один игрок, без сервера и ботов.
- **Игра с ботами** — 3 игрока, боты воюют, покупают улучшения и поднимают упавших.
- **P2P-комната** — хост создаёт комнату, гости входят по коду; до 8 игроков. Хост авторитетно считает игру, гости отправляют только ввод.

Платный VPS/Colyseus отменён — игра работает без него.

## Классы

Перед забегом выбери класс — он задаёт стартовое оружие и бонусы:

| Класс | Старт | Бонусы |
| --- | --- | --- |
| ⚔ Воин | меч | +20 HP, +10 урон, вампиризм |
| ➤ Стрелок | пистолет | +8 урон выстрела, быстрее стрельба, +20 скорость |
| ✜ Снайпер | пистолет | +14 урон выстрела, +10% крит, медленнее |
| ✦ Универсал | меч | +10 HP, сбалансированные урон/стрельба/скорость |

В руках всегда **одно оружие**. `Q` (или `E`) мгновенно меняет меч ↔ пистолет; `J` атакует тем, что сейчас в руках. Одновременно мечом и пистолетом пользоваться нельзя.

## P2P: как играть с другом

1. Хост: **«Создать комнату»**.
2. Скопируй **код** или **ссылку** (`…?room=XXXXXX`) и передай другу.
3. Друг открывает ссылку → код уже подставлен → **«Войти по коду»**.
4. Когда все подключились, хост жмёт **«Начать»**.

### Сигналинг

По умолчанию используются бесплатные публичные PeerJS-серверы:

```
0.peerjs.com → 1.peerjs.com → peerjs-server.onrender.com
```

Если они недоступны (например, блокируются провайдером), укажи свой сигналинг через параметр:

```
https://formahedon51.github.io/stickman-roguelike/?server=HOST:PORT:/peerjs
```

Подойдёт сервер на ноутбуке (в т.ч. PeerJS из старого `stickman-coop` через бесплатный туннель). Ссылка с `?server=…`, скопированная хостом, уже содержит этот параметр — гость автоматически будет использовать тот же сигналинг.

> Кооп требует работающий WebRTC (P2P). В некоторых сетях/встроенных браузерах он блокируется — тогда нужен VPN или другой браузер. Соло/боты работают всегда.

## Управление

| Клавиша | Действие |
| --- | --- |
| A / D / ← → | движение |
| W / Space / ↑ | прыжок |
| Shift | рывок |
| J / Z | атака текущим оружием |
| Q / E | сменить меч ↔ пистолет |
| 1 / 2 / 3 | купить в магазине |
| Space | «Готов» в магазине |
| Esc / P | пауза (соло) |
| M | звук |

На телефоне — экранные кнопки.

## Механики

- Классы, стартовое оружие и смена оружия в бою (одно активное).
- Волны, гранты/бруты/метатели, босс каждые 5 волн.
- Рывок с неуязвимостью, двойной прыжок, криты, мультивыстрел, пробивание, вампиризм, броня, магнит.
- XP и уровни, общие монеты, дроп монет/опыта, авто-сбор.
- Магазин между волнами: 3 предложения, редкости, уровни апгрейдов, общие монеты, «Готов».
- Нокдаун и подъём (в коопе), комбо, счёт, итоги, лучший результат.
- Внешность прошлой версии: арена с городом/луной, стикмены с оружием, партиклы, урон, декали, следы рывка, HUD, босс-бар, звук.

## Локальный запуск

```bash
cd client
python3 -m http.server 9100
# открыть http://127.0.0.1:9100/
```

ES-модули работают по HTTP, не по `file://`.

## Структура

```
client/
├── index.html
├── css/style.css
├── icon.svg
├── js/
│   ├── main.js        # меню, режимы, цикл, звук
│   ├── ui.js          # HUD, лобби, магазин, итоги
│   ├── render.js      # Canvas-рендер
│   ├── demo.js        # соло/боты
│   ├── p2p.js         # хост/гость PeerJS + снапшоты
│   ├── input.js       # клавиатура + тач
│   ├── audio.js       # SFX
│   └── config.js
├── shared/
│   ├── constants.js
│   ├── classes.js     # классы и бонусы
│   ├── sim.js         # авторитетная симуляция (без DOM)
│   └── upgrades.js
└── vendor/peerjs.min.js
```

`shared/sim.js` — чистая симуляция; её использует хост в браузере (и сможет использовать любой будущий сервер).
