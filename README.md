# Untitled X

Браузерный 2D-рогалик для одного игрока: классы, разное оружие, прокачка, волны и боссы. Без сети, серверов и мультиплеера.

**Игра:** https://formahedon51.github.io/stickman-roguelike/
**Репозиторий:** https://github.com/formahedon51/stickman-roguelike

## Режимы

- **▶ Играть** — обычный одиночный забег. Выбери класс и переживи как можно больше волн.
- **🤖 Бот-забег** — умный бот сам проходит игру выбранным классом: выбирает цель и оружие, уклоняется, покупает улучшения и играет магазин. Можно ускорить кнопкой `×1 → ×2 → ×4 → ×8` и смотреть.

Мультиплеер и кооп-боты убраны. Игра полностью локальная.

## Классы

| Класс | Арсенал | Стиль |
| --- | --- | --- |
| ⚔ Воин | меч, топор | танк с вампиризмом |
| ➤ Стрелок | пистолет, винтовка | темп и скорость |
| ✜ Снайпер | винтовка, пистолет | криты и дальность |
| ✶ Универсал | меч, пистолет | ровные бонусы |
| ⚒ Берсерк | топор, меч | стеклянная пушка |
| ⚙ Инженер | дробовик, пистолет | броня и регенерация |
| ✧ Маг | посох, кинжал | магия и криты |
| ⌁ Ниндзя | кинжал, пистолет | скорость и рывки |

## Оружие

| Оружие | Тип | Особенность |
| --- | --- | --- |
| Меч | ближний бой | быстрый и надёжный |
| Топор | ближний бой | медленный, очень тяжёлый удар |
| Кинжал | ближний бой | очень быстрый, повышенный крит |
| Пистолет | стрельба | универсальный точный выстрел |
| Дробовик | стрельба | 5 картечин вблизи |
| Винтовка | стрельба | дальний огонь, пробивает насквозь |
| Посох | стрельба | самонаводящийся снаряд |

В руках всегда **одно оружие**. `Q` / `E` переключает по арсеналу. В магазине можно докупить новое оружие — оно появится в арсенале.

Автонаведение учитывает скорость цели и не берёт цель сквозь стены/платформы. Попадания считаются по всей траектории за тик: быстрые пули не пролетают сквозь врагов, а хитбоксы врагов расширены под их тело и конечности. Улучшение **«Умные снаряды»** позволяет пулям и магии менять цель уже после выстрела.

## Управление

| Клавиша | Действие |
| --- | --- |
| A / D / ← → | движение |
| W / Space / ↑ | прыжок |
| Shift | рывок с неуязвимостью |
| J / Z | атака текущим оружием |
| Q / E | следующее оружие |
| 1 / 2 / 3 | купить улучшение |
| Space | «Готов» в магазине |
| Esc / P | пауза |
| M | звук |

На телефоне — экранные кнопки.

## Прокачка

41 улучшение: здоровье, броня, щит, регенерация, вампиризм, шипы, лечение за убийство, скорость, прыжки, рывки, урон и скорость ближнего боя, урон/темп/размер снарядов, мультивыстрел, пробивание, криты и сила критов, казнь, умные снаряды с перенаведением, урон по боссам, ярость при низком HP, магнит, опыт, монеты, ускоренная смена оружия и разблокировка шести видов оружия.

## Бот

Бот не просто жмёт кнопки:

- выбирает цель по угрозе и дистанции;
- автонаведение учитывает движение врага и не стреляет сквозь стены и платформы;
- сначала чистит мелочь, чтобы не оказаться в окружении;
- подбирает оружие под дистанцию и переключается с гистерезисом;
- уклоняется от снарядов, рывков и атак босса;
- не отступает в стену, выпрыгивает из угла;
- при низком HP отходит на регенерацию;
- сам покупает улучшения по приоритету и автоматически завершает магазин.

Для проверки ботом прогонялись все 8 классов: без ошибок симуляции, с выходом на 30+ волн и выше.

## Локальный запуск

```bash
cd client
python3 -m http.server 9100
# открыть http://127.0.0.1:9100/
```

ES-модули работают по HTTP, не по `file://`.
