# STICKMAN CO-OP · ROGUELIKE — клиент (Colyseus)

Браузерный 2D-рогалик на **1–8 игроков** в реальном времени. Это клиентская часть: Canvas, ввод, HUD, магазин, эффекты и демо-режим. Серверная часть (Colyseus + VPS + Caddy) **пока не добавлена** — её делаем после появления сервера.

**Постоянная ссылка (GitHub Pages):** https://formahedon51.github.io/stickman-roguelike/

## Что уже работает

- **Одиночная игра** без сервера — локальная симуляция прямо в браузере (как в прошлой версии).
- **Игра с ботами** — 3 игрока в демо; боты воюют, покупают улучшения и поднимают упавших.
- **Пауза в соло** (Esc/P) и звук/mute.
- **1–8 игроков**: HUD на любое число игроков, классы «воин» (меч) и «стрелок» (пистолет) по чётности.
- **Внешность из прошлой версии**: тёмная арена с городом, луной, сеткой и платформами; стикмены с шарфом, свечением и оружием; тени, партиклы, декали, следы рывка, цифры урона, спавн-маркеры, виньетка.
- **Механики прошлой версии**: волны, гранты/бруты/метатели, босс каждые 5 волн, рывок с неуязвимостью, двойной прыжок (апгрейд), криты, мультивыстрел, пробивание, вампиризм, броня, магнит.
- **XP и уровни**, общие **монеты**, дроп монет/опыта, магнит, авто-сбор после волны.
- **Магазин между волнами**: 3 предложения, редкости (обычное/необычное/редкое/легендарное), уровни апгрейдов, общие монеты, «Готов».
- **Нокдаун и подъём**: если есть живой напарник — падаешь, теряешь HP; напарник рядом поднимает. Если все упали — итоги.
- **Комбо за убийства**, счёт, босс-бар, экран итогов, лучший результат.
- **Сенсорное управление** и **звук** (mute).
- **Адаптер Colyseus**: поле адреса сервера в меню, подключение к комнате `roguelike_room`.

## Запуск локально

```bash
cd client
python3 -m http.server 9100
# открыть http://127.0.0.1:9100/
```

ES-модули работают только по HTTP, не по `file://`.

## Управление

| Клавиша | Действие |
| --- | --- |
| A / D / ← → | движение |
| W / Space / ↑ | прыжок |
| Shift | рывок |
| J / Z | удар |
| K / X | выстрел |
| 1 / 2 / 3 | купить в магазине |
| Space | «Готов» в магазине |
| Esc / P | пауза (соло) |
| M | звук |

На телефоне — экранные кнопки.

## Подключение будущего сервера

1. Подними Colyseus-сервер (см. `PROTOCOL.md`).
2. В меню игры укажи адрес: `wss://45-12-34-56.sslip.io` (или свой домен).
3. Нажми «Подключиться». Клиент создаст/найдёт комнату `roguelike_room`.

Соло и боты — это **не** сервер: они существуют только для игры/проверки клиента. В реальной многопользовательской игре авторитетная симуляция выполняется на сервере; клиент отправляет только ввод.

## Структура

```
client/
├── index.html
├── css/style.css
├── icon.svg
├── js/
│   ├── main.js        # меню, сессии, цикл, звук
│   ├── ui.js          # HUD, магазин, итоги, обучение
│   ├── render.js      # Canvas-рендер (арена, стикмены, эффекты)
│   ├── demo.js        # демо-симуляция + боты
│   ├── net.js         # адаптер Colyseus
│   ├── input.js       # клавиатура + тач
│   ├── audio.js       # SFX
│   └── config.js
├── shared/
│   ├── constants.js   # арена, физика, типы врагов
│   ├── sim.js         # авторитетная симуляция (без DOM)
│   └── upgrades.js    # магазин и редкости
└── vendor/colyseus.js
```

`shared/sim.js` не использует DOM и может исполняться на сервере (ESM) — это задел под Colyseus.

## Серверная часть (не входит)

По договорённости сервер/VPS/Caddy пока не трогаем. Когда сервер появится:

- Colyseus-комната `roguelike_room`, `maxClients: 8`;
- тик 20 Гц, приём ввода 30 Гц;
- сообщения `input`, `shopBuy`, `shopReady`, `restart`, `game_over`;
- контракт состояния — в `PROTOCOL.md`.
